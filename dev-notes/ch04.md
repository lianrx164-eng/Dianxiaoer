- **用户原话要点**:混合检索(Milvus 原生 BM25 + dense,hybrid_search RRF)、bge-reranker-v2-m3 重排 Top-10、元数据过滤、Query 改写与同义词、引用/拒答/低置信度池/负面知识、四策略评估、聊天页可点引用与 👍/👎;全程 Superpowers,dev-notes 分阶段追记,库/API 先查 Context7,选型矛盾停下问。
- **产出**:读入桌面 Spec(`Sepc.md`)、Plan、`ch_04.sql`、4 份知识文档、300 题评估集;产出设计修订版 `docs/superpowers/specs/2026-11-14-ch04-hybrid-retrieval-rerank-eval-design.md`、计划修订版 `docs/superpowers/plans/2026-11-14-ch04-hybrid-retrieval-rerank-eval.md`、`sql/ch04-ddl.sql`、`tests/data/eval_ch04.jsonl`、补齐后的 `data/kb/*.md`。
- **用户纠偏/拍板**:
  1. Milvus 部署:原选 Docker Desktop,后实测 milvus-lite 3.2.2 已支持 BM25 + hybrid_search,用户拍板「改用 Lite」,Docker 下载中止。
  2. 重排:用户拍板「百炼 qwen3-reranker」,实际模型名 `qwen3-rerank`。
  3. 嵌入:用户拍板沿用百炼 `text-embedding-v4`。
  4. 评估集:用户确认 A/B/C/E 四个可作答桶各 60 + D 库外 60,共 300。
  5. KB 与评估集对不上(46 个要点无依据):用户拍板「按评估集补全 KB」。
- **翻车与返工**:
  - Docker Desktop 下载 83/595 MB 后按现速需数小时,期间实测 Lite BM25 可行,避免了一次长时间的无效等待。
  - 桌面三份 Markdown 标题粘在一行(`# 退货退款政策## 无理由退货### 适用范围`),已按行拆开;内容未改。
  - 百炼 OpenAI 兼容网关的 `/reranks`、`/rerank` 均 404;原生 DashScope 路径 `https://maas.qianwenaiapi.com/api/v1/services/rerank/text-rerank/text-rerank` 可用。
  - Milvus Lite 不识别 `analyzer_params={"type":"chinese"}`,报 `unknown tokenizer type: 'chinese' (supported: 'standard','jieba')`;改 `{"tokenizer":"jieba"}` 并安装 `jieba` 后通过。
  - Lite COSINE 实测 `distance` 即相似度(identical=1.0),Plan 里「Lite 返回 1−相似度」的说法已纠正。
